刷写之前请注意

为某个硬件版本编译的固件会把另一个版本刷成砖。请先确认你手上是哪款对讲机，并先备份校准数据——它是你这台对讲机独有的，没有人能把它还给你。

我的对讲机是哪一款？#

关闭对讲机，按住 PTT 再开机：屏幕会显示 Bootloader（引导程序）版本号。它的第一位数字就代表硬件版本。

Bootloader 开头数字对讲机Karina 版本
2、3、4、5UV-K5 V1karina-v1（独立仓库）
1UV-K5 V2不支持
7UV-K5 V3、UV-K1、UV-K1(8)本仓库

V1 机型没有任何标识；V2 和 V3 通常在电池下方的标签上有标注。

还在用较早的 UV-K5 V1？它有自己的固件，放在另一个仓库里： autumn1rain/karina-v1

Karina 新增的功能#

频谱分析仪

内置波段预设和自由输入模式，可实时捕获当前有信号的频率，支持噪声频道黑名单，并可调节衰减器、AGC 和静噪。

更听话的扫描

支持扫描列表、扫描过程中检查优先频道，还可以打开某个频道的衰减器，在扫描中随时跳过它。

亚音扫描

在当前频率上扫描 CTCSS/DCS 亚音，并把扫到的亚音保存为发射亚音。

调频广播

支持电台搜索和记忆，工作频道上的信号消失五秒后自动恢复收听。

三级衰减器

可按频率或频道设置 ATT1、ATT2 和 ATT3——在大功率发射台旁边很有用，也可用于扫描时跳过频道。

功率、电池及其他

HIGH / MID / LOW 三挡发射功率、重新设计的省电模式、动态音量、频率与功率随机化、NOAA、AM 和 USB 调制。

安装#

这里是简要步骤。带截图的完整流程见下方的安装指南。

  1. 趁对讲机还运行着当前固件，先备份你的校准数据和配置。
  2. 关闭对讲机，按住 PTT 再开机——这就是刷写模式。
  3. 用下面任意一个工具刷入适合你对讲机的文件。
  4. 清除内存：先关机，然后按住 PTT + EXIT 约两秒再开机。
  5. 先把你自己的校准数据写回去，然后写入发布包中的 Karina 校准数据。
  6. 复位对讲机：MENU → RESET → VFO。

常见问题#

可以把它刷进 UV-K5 V1 吗？

不可以。V1 使用不同的处理器和不同的 Bootloader（引导程序），刷错固件会把对讲机变成砖。V1 用户需要使用 karina-v1 版本。

我真的必须备份校准数据吗？

是的。校准数据保存着你这台对讲机自己的发射功率和电池参数。它不包含在任何发布包里，也没有人能替你恢复。

可以保留我在其他固件上的设置吗？

不可以。只有从早期 Karina 版本保存下来的配置才能写回。频道可以用 CHIRP 迁移。

用 CHIRP 写入设置后，对讲机要求输入密码。

这是因为某个侧键被留成了 NONE。写入前请把四个侧键功能全部填好（两个按键的短按和长按）。

我可以去哪里求助？

到 Telegram 聊天群的评论区提问。请说明你用的是哪款对讲机、哪个固件版本。
